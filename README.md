# ⚠️ Common Prompt Engineering Mistakes

## ❌ Using Very Short Prompts
### Bad Prompt:
Explain Java

### Better Prompt:
Explain Java in simple terms with examples and key features for beginners.

### Why?
Detailed prompts give better AI responses.

---

## ❌ Asking Multiple Questions Together
### Bad Prompt:
Explain DBMS, Java, Python, and Networking.

### Better Prompt:
Explain DBMS basics with real-life examples.

### Why?
Focused prompts produce clearer answers.

---

## ❌ Not Mentioning Output Format
### Bad Prompt:
Teach me OOP concepts.

### Better Prompt:
Explain OOP concepts in bullet points with Java examples.

### Why?
Specifying format improves readability.

---

## ❌ Ignoring Context
### Bad Prompt:
Create a timetable.

### Better Prompt:
Create a 7-day study timetable for a CSE student preparing for semester exams.

### Why?
Context helps AI generate personalized responses.

---

## ❌ Using Confusing Language
### Bad Prompt:
Tell everything about coding stuff.

### Better Prompt:
Explain the basics of Java programming for beginners.

### Why?
Clear prompts give accurate outputs.

---

## ❌ Expecting Perfect Answers Instantly
### Mistake:
Using only one prompt and stopping.

### Better Approach:
Refine prompts step-by-step for better responses.

### Why?
Prompt engineering is an iterative process.
